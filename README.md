# Fußpflege Hand & Fuß

One-Page-Website für Fußpflege Hand & Fuß in Nürtingen, im Design von feinschliff-nuertingen.de.
Next.js + Tailwind CSS, Hosting auf Vercel.

## Lokal starten

```bash
npm install
npm run dev
```

Dann http://localhost:3000 öffnen.

## Inhalte ändern

Alle Texte, Preise und Kontaktdaten stehen in `lib/content.ts`.
Impressum und Datenschutz stehen in `components/Legal.tsx`.
